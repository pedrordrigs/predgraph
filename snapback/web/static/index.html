Graduation — thresholds fixed before the run started

Set in advance so the run can't be talked into looking good afterwards; changing one mid-run resets the clock. The strategy is positive-skew — the median trade loses and a minority of large winners carry it — so an early losing streak proves nothing.

Two rules, one tape

Both rule sets see identical quotes and keep separate $1,000 books, so a signal clearing both opens a position in each. The wider dials came from a sweep of ~40 configurations, which makes their backtest numbers optimistic by construction — running both live is the only measurement that isn't.

Backtested expectation — the line to beat

The wide rule held in both calendar halves, survived collapsing to one unit per event-day (+0.097, CI [+0.044, +0.163]), and was significant on Kalshi where the calibrated rule was not. Break-even cost 9¢ against ~1–2¢ live spreads. Treat these as a ceiling, not a forecast.
